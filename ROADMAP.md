# 🗺️ Future Features

## Planned Enhancements

### 🔐 Security
- [ ] **Forward Secrecy** - X25519 + Double Ratchet (Signal Protocol)
- [ ] **Fingerprint Verification** - QR codes and safety numbers
- [ ] **Key Rotation** - Automatic periodic key updates

### 💬 Features
- [ ] **Offline Messages** - Store and deliver when user comes online
- [ ] **Group Messaging** - Encrypted group chats with sender keys
- [ ] **File Transfer** - Encrypted file sharing
- [ ] **Message History** - Secure local storage
- [ ] **Read Receipts** - Message delivery confirmation
- [ ] **Typing Indicators** - Real-time typing status

### 🖥️ User Interface
- [ ] **Desktop GUI** - PyQt6 graphical interface
- [ ] **Web Client** - Browser-based chat (WebSockets)
- [ ] **Mobile App** - Android/iOS support (Kivy)
- [ ] **Dark Mode** - Theme support
- [ ] **Emoji Support** - Rich text messaging
- [ ] **Notifications** - Desktop/mobile notifications

### 🏗️ Infrastructure
- [ ] **Database Backend** - PostgreSQL/MySQL support
- [ ] **Redis Cache** - Message queue and session management
- [ ] **Load Balancing** - Multiple server instances
- [ ] **Docker Support** - Containerized deployment
- [ ] **CI/CD Pipeline** - Automated testing and deployment

## Implementation Priority

**Phase 1** (High Priority):
1. Fingerprint Verification UI
2. Forward Secrecy (X25519 + Double Ratchet)

**Phase 2** (Medium Priority):
3. Offline Message Storage
4. Basic Desktop GUI (PyQt6)

**Phase 3** (Future):
5. Group Messaging
6. Mobile/Web Clients

See `ROADMAP.md` for detailed implementation plans.
